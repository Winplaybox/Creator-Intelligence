# Creator Intelligence Mobile

Expo React Native starter for Android and iOS.

## Prerequisites
- Node.js supported by the selected Expo SDK
- pnpm 9
- Expo Go or native development build

## Commands
From repository root:
- `pnpm --filter @creator-intelligence/mobile start`
- `pnpm --filter @creator-intelligence/mobile android`
- `pnpm --filter @creator-intelligence/mobile ios`

## Current scope
This PR adds a mobile app shell and workspace feature preview. Authentication, API client, secure token storage, navigation, push notifications, and live data integration are not implemented yet.
